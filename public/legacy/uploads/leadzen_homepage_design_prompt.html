04 Tips for Best Results

For Claude (claude.ai): Use the Projects feature or a fresh conversation. Paste the entire Master Prompt in one message. If the output truncates, follow up with "Continue from [section name]". For best results, request a single HTML file.

For other AI design tools: The prompt works with Cursor, Bolt.new, v0, and Lovable. Append "Use Tailwind CSS" only if the tool natively supports it. Otherwise, the embedded CSS approach is more reliable.

What to check in the output: Verify the dot grid renders on the hero, the floating demo card has the animation, all 6 feature cards have correct accent border colors, the gradient text on the headline works, and the stats count up on scroll. These are the most commonly dropped elements in AI-generated outputs.

If you want to modify the copy: The copy section above (Section 02) contains every word. Edit there first, then include the updated copy in the prompt. Never ask the AI to "figure out the copy" — always provide it explicitly for a homepage.
